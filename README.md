# 📘 Excel-Based Test Automation Framework (Java + TestNG)

This repository contains a Java-based automation framework designed to **drive test cases using data from Excel files**. It includes reusable **utility classes**, and functions for **file upload/download**, making it suitable for real-world automation scenarios.

---

## 🚀 Overview

This project demonstrates how to:
- Read test data from **Excel files** using Apache POI
- Use the data to perform **automated tests**
- Upload and download files through APIs or web interfaces
- Maintain reusable utility classes for improved scalability and modularity

---

## 🔧 Tech Stack

| Feature                | Technology           |
|------------------------|----------------------|
| Programming Language   | Java                 |
| Build Tool             | Maven                |
| Test Framework         | TestNG               |
| Excel Integration      | Apache POI           |
| Logging                | Log4j2               |
| Reporting              | ExtentReports (optional) |
| Data Faker (Optional)  | Java Faker Library   |
